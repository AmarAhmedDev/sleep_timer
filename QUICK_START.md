# Quick Start Guide - Smart Sleep Timer

## 🚀 Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
flutter pub get
```

### Step 2: Run the App
```bash
flutter run
```

### Step 3: Build APK
```bash
flutter build apk --release
```

Or simply double-click `build_apk.bat` on Windows!

---

## 📱 First Time Setup

After installing the app, you'll need to grant permissions:

### 1. Usage Access (Most Important!)
- Tap "Grant Permission" when prompted
- Find "Smart Sleep Timer" in the list
- Toggle ON

### 2. Display Over Other Apps
- Tap "Grant Permission" when prompted
- Toggle ON

### 3. Battery Optimization
- Select "Don't optimize" or "Allow"

---

## 🎯 How to Use

### Set a Timer:
1. Open the app
2. Tap a preset button (5, 10, 20, 30, 60 min)
3. Or tap "Custom" to set your own time
4. Timer starts automatically!

### While Timer is Running:
- App shows countdown
- Notification appears in status bar
- You can use other apps normally
- Timer continues in background

### When Timer Ends:
- Media apps automatically close
- Device audio mutes
- Notification shows "Sleeping mode activated"
- Screen goes to home

## ⚙️ Customize Settings

Go to Settings tab to:
- Toggle dark/light mode
- Enable/disable vibration
- Choose stop method (Force Close / Mute / Pause)
- Enable No Sleep Mode (parental control)

## 💡 Pro Tips

1. **For Best Results**: Grant all permissions when prompted
2. **Battery Saver**: Disable battery optimization for the app
3. **Parental Control**: Enable "No Sleep Mode" in settings
4. **Background Running**: Keep the app in recent apps (don't swipe away)

---

## ❓ Common Issues

**Timer doesn't stop media?**
- Make sure Usage Access permission is granted
- Check battery optimization is disabled

**Timer stops in background?**
- Disable battery saver mode
- Grant battery optimization exception

**No notifications?**
- Check notification permission
- Ensure Do Not Disturb is off
